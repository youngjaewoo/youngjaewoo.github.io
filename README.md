# Youngjae Woo

Personal blog built with Astro and styled after [Astro Cactus](https://github.com/chrismwilliams/astro-theme-cactus).

## Write a post

Create a Markdown file in `content/posts/`:

```markdown
---
title: "A post title"
description: "A short description of the post."
publishDate: 2026-08-25
tags: []
---

Write your post here in Markdown.
```

Run `npm install`, then `npm run dev` to preview the site locally. Run `npm run build` to create the static site in `dist/`.
